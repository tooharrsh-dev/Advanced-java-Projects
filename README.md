## About This Repository
This repository contains six Java lab experiments and one complete Java-based web application. It demonstrates practical knowledge of Java programming, database connectivity, networking, and web development.

## Java Lab Experiments

1. Student Registration Form – A form-based application for collecting student information.
2. Calculator – Performs basic arithmetic operations.
3. JDBC – Connects Java applications with a database.
4. RMI – Enables communication between Java objects running on different systems.
5. Server-Client Communication – Demonstrates data exchange between a server and a client.
6. Servlet – Handles client requests and generates dynamic web responses.

## Major Project: ShopSphere
ShopSphere is a Java-based web application designed around an online shopping experience. It displays product information and uses a MySQL database to store product details.
